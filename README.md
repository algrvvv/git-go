# git-go 

**git-go** — это современная CLI-утилита и Git-подкоманда, написанная на Go, которая служит интеллектуальным слоем навигации и управления ветками в Git. 

Утилита решает проблему поиска нужной ветки среди сотен старых или плохо названных веток, используя **метаданные**, **интерактивный TUI** и **умный поиск**.

---

## Ключевые возможности

-  **Интерактивный режим (`git go`)**: Полноценный терминальный интерфейс с фильтрацией в реальном времени, подсветкой текущей ветки и отображением метаданных.
-  **Умный поиск и переключение (`git go <query>`)**: Поиск по имени ветки и её описанию (`git config branch.<name>.description`) с алгоритмами ранжирования и подсчета релевантности.
-  **Создание ветки с метаданными (`git go -b <branch> <meta>`)**: Быстрое создание новой ветки с одновременным сохранением человекочитаемого описания.
-  **Управление описаниями (`git go --meta`)**: Удобное редактирование метаданных для текущей или указанной ветки через `git branch --edit-description`.
-  **Список веток (`git go --list`)**: Быстрый вывод всех веток с их описаниями и датами последнего коммита.

## Установка и сборка

### Требования
- Go 1.26 или выше
- Установленный Git

### Сборка из исходников
```bash
git clone https://github.com/algrvvv/git-go.git
cd git-go
go build -o git-go main.go
```

Чтобы Git распознал утилиту как подкоманду `git go`, переместите бинарник в директорию, доступную в переменной `$PATH`:
```bash
sudo mv git-go /usr/local/bin/git-go
```
После этого вам станет доступна команда `git go`.

## Использование и примеры команд

### 1. Интерактивный режим (TUI)
Запуск без аргументов открывает интерактивный список всех веток с мгновенной фильтрацией по вводу:
```bash
git go
```
*Навигация:* стрелки вверх/вниз (или `j`/`k`), ввод для переключения, `Esc` или `Ctrl+C` для отмены.

### 2. Поиск и переключение по запросу
```bash
git go "checkout action"
```
Утилита найдет наиболее релевантную ветку по имени или описанию и переключится на нее.

### 3. Создание новой ветки с описанием
```bash
git go -b feature/login-page "Implement OAuth2 login flow"
```
Создает ветку `feature/login-page` (через `git checkout -b`) и сохраняет описание в конфигурации git (`branch.feature/login-page.description`).

### 4. Просмотр списка веток
```bash
git go --list
```
Выводит список всех веток с их метаданными.

### 5. Редактирование метаданных ветки
Для текущей ветки:
```bash
git go --meta
```
Для конкретной ветки:
```bash
git go --meta feature/login-page
```

## Тестирование

Запуск в режиме отладки, чтобы увидеть почему была выбрана для перехода именно эта ветка:
```bash
git go --debug
```
